# Lightweight Concealed Weapon Detection in PMMW Images

This project prepares the SAIR-U dataset, compares lightweight YOLO models, and evaluates a selected YOLO11n concealed-gun detector.

Use Python 3.13, install `CWD/requirements.txt`, and open `CWD/msc-major-project-cwd.ipynb` from the `CWD` directory. Place the SAIR-U data in `CWD/pmmw-dataset` and the required pretrained YOLO weights beside the notebook.

Training is computationally expensive and is only required when reproducing the experiments.
